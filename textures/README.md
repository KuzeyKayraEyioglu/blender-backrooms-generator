# Optional Sample Textures

These optional seamless textures can be used with Backrooms Generator.

They are not required for the add-on to function. Users can also select their
own wall, floor, and ceiling textures from the add-on panel.

## Included Textures

- Seamless Backrooms-style wall texture
- Seamless carpet texture
- Seamless ceiling-tile texture

## Usage

1. Open the Backrooms Generator panel.
2. Select the desired image under Wall Texture, Floor Texture, or Ceiling Texture.
3. Adjust the tiling settings if needed.
4. Generate the environment.
